-----------------Short Explanation of the principles of CIA used in this program-----------------

This program upholds the Confidentiality (C) and Integrity (I) of the CIA Triad in Cybersecurity. It does this by limiting the access of the program to only authorized users. It authenticates the user trying to login. If the user's credentials match to one in the database, it next checks for authorization for access to the program. It authorization passes, then the user is granted access and is able to use the program. This is the C of the CIA Triad in action. The other part of the Triad being used is the I. It checks the initial hash of the message trying to be sent using a generated Symmetric key against the decrypted hash using the same key that was used to encrypt it. If the two hashes match, then the integrity of the message is upheld. If the hashes differ, then the integrity of the message has been compromised. 

-----------------------------Role of Entropy and Key Generation----------------------------------

The role of Entropy and Key Generation in Cryptography is crucial. Computers are built to be precise. It may sound counterintuitive to say that randomness is crucial in keeping computer systems secure. Introducing randomness into security measures or when keeping sensitive data secure is necessary. This is where the topic of entropy comes from. Entropy is the theory of the measure of randomness. This randomness excels when using the concept with hashing sensitive data or even with the generation of public and private keys. The role of key generation is also important because it plays into the "C" of the CIA Triad. Using generated keys, whether they be public or private, helps assure that only the intended recipient of the encrypted message has access to the contents of the message. Encryption within the transmission of data prevents any unauthorized or malicious persons from manipulating or stealing the data in transit.
